## 🕹️ Доступные игры

1.  **Угадай число** — компьютер загадывает число, а вы пытаетесь его отгадать.
2.  **Простая арифметика** — несколько легких примеров.
3.  **Переверни текст** — компьютер переворачивает написанное тобой слово.
4.  **Простая викторина** — вопросы с выбором ответа и подсчетом очков.
5.  **Камень-Ножницы-Бумага** — игра против компьютера со счетом.
6.  **Генератор случайных цветов** — можно изменить цвет фона.

## ✨ Реализованный функционал

*   **Полная играбельность:** каждая игра имеет начало, игровой процесс и конец.
*   **Адаптивный интерфейс** для всех устройств.
*   **Простое переключение** между играми без перезагрузки страницы.

## 🚀 Как запустить локально?

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/nuna-f-ck/site-games-2.git
    ```
2.  Перейдите в папку проекта:
    ```bash
    cd site-games-2
    ```
3.  Откройте файл `index.html` в браузере или используйте Live Server в VS Code.
